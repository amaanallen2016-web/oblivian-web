# OblivianOS

OblivianOS is an aesthetic all-in-one desktop experience built as a single-page web app. It includes:

- App launcher / desktop shell
- App Center with a curated game catalog
- Messaging app with usernames and live chat via Socket.IO
- Wallpaper Lab with animated / aesthetic wallpaper switching
- Music app with playlist-style track player
- Settings panel and desktop customization
- Doblox-inspired game launcher
- PS4 emulator prototype launcher UI
- Secure Search / web proxy UI stub for browser access

This project is designed as a front-end prototype and local development environment. It is not a full replacement for a Linux operating system, nor is it a claim to have real PS4 console emulation or copyrighted game distribution.

## Tech stack

- Node.js
- Express
- Socket.IO
- HTML / CSS / JavaScript

## Run locally

1. Install dependencies:
   npm install
2. Start the app:
   npm start
3. Open:
   http://localhost:3000

## Repository notes

This project was created by amaanallen2016-web. All original desktop UI, JS logic, and project structure are included here.

The repository intentionally uses legal/open-content placeholders and metadata, not copyrighted game binaries or commercial music/media packs. If you want to expand it with your own owned assets or additional game data, you can drop them into the project and point the app to them.
